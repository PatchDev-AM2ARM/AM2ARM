AM2ARM Linux Autopatcher

The Linux release has one ARM64 ZIP. From the repository root, read README.md
for installation on your particular firmware, the required card paths and the
published hardware verification.

The program uses the original Windows AM2R 1.1 ZIP to build the game's archive.
The installer is in autopatcher/linux. The firmware entry scripts and the game
launcher are in native/unified, and gmloader-next in native/gmloader. See
docs/README.md to restore source inputs.
